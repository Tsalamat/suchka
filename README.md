# Lane Detector — Flutter + Rust (всё считается на телефоне)

Живая камера на весь экран -> Rust (фильтр узких светлых полос + Hough + точка схода) -> линии разметки поверх картинки.
Зелёная линия — прерывистая, жёлтая — сплошная.
Рисуются только отрезки, реально найденные в текущем кадре. Никакой дорисовки и памяти между кадрами.
Если разметки нет — на экране «Разметка не обнаружена».

## Как получить APK без установки чего-либо на компьютер
1. Создайте репозиторий на github.com и загрузите в него содержимое этой папки (включая `.github`).
2. Откройте вкладку **Actions** -> **Build APK** -> **Run workflow**.
3. Через ~8–12 минут в разделе **Artifacts** скачайте `lane-detector-apk` (внутри `app-release.apk`).
4. Скопируйте на телефон и установите (разрешите установку из неизвестных источников).

## Управление
- «Чувствительность» — больше = находит бледную разметку, но может ловить лишнее.
- «Зона» — показать область поиска (трапеция).
- Приложение работает в альбомной ориентации (телефон на торпедо, камера смотрит вперёд).

## Ограничения
- Классический алгоритм, не нейросеть: может принять тень, трещину, край асфальта за линию.
- Не для управления автомобилем и не для систем безопасности.
